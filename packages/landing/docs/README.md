# resume documentation

**resume** is a Rust CLI that turns a YAML or JSON resume into Markdown, PDF,
HTML and validated output — plus a `serve` HTTP mode and an MCP server. This
site also hosts a browser-based resume editor that exports YAML matching the
`resume-core` schema.
