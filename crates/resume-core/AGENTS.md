# AGENTS.md — resume-core

Core resume logic shared by the CLI and the WASM build used by `packages/landing`.
See the root [`AGENTS.md`](../../AGENTS.md).

- `src/types.rs` — `ResumeData` and all section structs; serde `camelCase` matches
  both the YAML/JSON schema and the template field names.
- `src/load.rs` — `parse_resume_yaml` / `parse_resume_json` / `to_json` / `to_yaml` and
  `DEFAULT_RESUME_YAML` (the `resume init` scaffold).
- `src/markdown.rs` — `to_markdown(&ResumeData) -> String`.
- `src/description.rs` — `format_description`, the `{{description}}` template
  helper (HTML-escaped, `<br>` line breaks, `•` bullets).
- `src/validate.rs` — `validate(&ResumeData) -> Result<(), String>`, fail-fast.
- `src/templates.rs` + `templates/` + `build.rs` — 64 minijinja templates
  embedded at compile time; `list_templates()` / `render_html(data, name)`.
  Templates are generated — do not edit by hand; see
  `scripts/convert_templates.py`.
- `src/wasm.rs` — `#[wasm_bindgen]` exports, all string-in/string-out:
  `resume_default`, `resume_empty`, `resume_parse`, `resume_parse_yaml`, `resume_serialize_yaml`,
  `resume_serialize_json`, `resume_to_markdown`, `resume_render_html`, `resume_validate`,
  `resume_list_templates`, `resume_format_description`. JS callers must `await init()`
  (default export) once before calling the `resume_*` functions.
- Pure library: no clap, no file I/O, no processes — everything is
  `wasm32-unknown-unknown` compatible.
- `crate-type = ["rlib", "cdylib"]` — `cdylib` for the wasm artifact.
- `package.json` + `Makefile` make this crate a pnpm workspace package
  (`@resume/core`); `pkg/` is generated by `make build-wasm`
  (`wasm-bindgen --target web`, CLI `0.2.130`) and is gitignored — CI builds
  it before the landing build. Do not hand-edit it.
- Build wasm: `make build-wasm` or `pnpm --filter @resume/core run build:wasm`
  (needs the `wasm32-unknown-unknown` Rust target).
